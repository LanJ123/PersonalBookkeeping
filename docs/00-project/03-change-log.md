# 变更记录

## CR-001：调整 Android 平台下限与设备矩阵

| 项目 | 内容 |
|---|---|
| 提出日期 | 2026-07-21 |
| 提出人 | 用户 |
| 状态 | 已撤销（CR-002） |
| 关联决策 | DEC-006、DEC-014、DEC-015 |

### 变更内容

- `minSdk` 从 Android 9（API 28）调整为 Android 8.0（API 26）。
- 删除 API 37 模拟器及 Android 17 前向兼容测试项。
- `compileSdk` 与 `targetSdk` 继续保持 API 36。

### 影响分析

- 需求：更新 NFR-030、Q-001 和需求基线中的兼容性下限。
- 技术：API 26 已提供 `java.time`；应用锁统一通过 AndroidX Biometric，并为 API 26/27 保留能力检测和兼容分支。
- 测试：最低版本模拟器改为 API 26，并增加 API 27 认证兼容检查；不再准备 API 37 系统镜像。
- UX、数据模型、备份格式与 MVP 功能范围不受影响。

### 验收结果

- 所有需求与技术设计文档不再把 API 28 表述为最低支持版本。
- 设备矩阵不再包含 API 37 / Android 17。
- 技术追踪矩阵、风险清单和 ADR 已同步。

## CR-005：首页流水、年月筛选与分类构成调整

| 项目 | 内容 |
|---|---|
| 提出日期 | 2026-07-26 |
| 提出人 | 用户 |
| 状态 | 已接受并完成设计与实现同步 |
| 影响页面 | 首页、流水、记账编辑器、统计 |

### 变更内容

- 首页在今日支出、本月支出、本月收入下方展示当前自然月的全部流水，按发生时间倒序；仍不提供首页月份切换。
- 流水页增加年月选择、上一月、下一月和清除月份，可直接查询任意有效年月的流水，并可继续叠加类型、账户、分类和备注条件。
- 记账编辑器移除“最近流水”区域及其后台查询，只保留本次记账所需字段、日期时间和保存反馈。
- 统计页分类构成采用环形图；支持支出、收入切换，分类排行逐项展示笔数、金额和占比，并可下钻到同周期、同收支类型、同分类的流水。

### 边界与不变项

- 首页流水范围固定为设备当前自然月；统计页历史周期选择不会改变首页。
- 环形图不统计转账；支出分类金额总和对账周期支出，收入分类金额总和对账周期收入。
- 任意日期范围筛选仍保留；应用自定义日期范围后解除年月快捷筛选的选中状态。
- 数据库 schema 和备份格式不变；分类笔数与金额均从事实流水实时聚合。

### 同步范围

- 需求：FR-031、FR-040～042、US-004、US-006、信息架构、数据一致性与需求基线。
- UX：`docs/02-design/ui/01～08` 更新为 v1.2。
- 实现：首页月流水聚合、流水年月筛选、编辑器查询精简、支出/收入分类构成及笔数聚合。

## CR-006：首页日分组与统计图表联动完善

| 项目 | 内容 |
|---|---|
| 提出日期 | 2026-07-27 |
| 提出人 | 用户 |
| 状态 | 已接受并完成设计与实现同步 |
| 影响页面 | 首页、统计 |

### 变更内容

- 首页当前月流水按本地发生日期聚合；每个日期组显示日期、星期、当日支出和当日收入小计，组内按发生时间倒序。
- 统计页增加全局 `支出 / 收入` 筛选；周期汇总、单类型趋势、分类构成、分类下钻和最近五周期对比统一跟随所选类型。
- 周/月/年汇总卡固定采用 2×2 结构：周期总额、日均金额、比上一周期差额、收支结余。
- 趋势图显示人民币纵轴刻度且一次只绘制所选类型；周期对比柱顶部显示金额；环形图在图形周围直接标注分类名和占比，排行继续显示笔数、金额、占比。

### 边界与不变项

- 日期分组以每笔流水保存的 `zone_id` 与 `local_date_epoch_day` 为准，不使用展示设备临时换算日期。
- 支出/收入筛选不包含转账；切换类型不改变所选周/月/年和周期。
- 收支结余始终为周期收入减周期支出，切换筛选时保持一致。
- 数据库 schema 和备份格式不变；新增图表数据均由现有事实流水聚合。

### 同步范围

- 需求：FR-030、FR-040～042、US-006、信息架构、追踪矩阵与需求基线更新至 v1.3。
- UX：`docs/02-design/ui/01～08` 更新为 v1.3。
- 实现：首页日分组与小计、统计类型状态、收入日均/周期对比、图表轴与数据标签。
