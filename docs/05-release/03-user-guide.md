# PersonalBookkeeping 用户手册

## 开始使用

首次打开后，应用会建立默认现金账户和常用分类。底部导航可进入首页、流水、统计和设置；右下角新增按钮用于记一笔。

## 日常记账

1. 点击新增按钮，选择支出、收入或转账。
2. 输入金额，选择账户和分类；转账需选择转出与转入账户。
3. 可填写日期和备注，确认后保存。
4. 在流水页按月份、类型、账户或分类筛选；进入详情后可编辑或删除。

## 统计与预算

首页显示当月收入、支出和结余。统计页可查看分类排行与趋势并下钻到流水。预算页可设置总预算和分类预算，接近或超出时会显示文字状态。

## 备份、恢复与 CSV

在“设置 → 数据与备份”中：

- “创建完整备份”生成 `.pbk` 文件，请保存到自己可控的位置。
- “恢复完整备份”会先校验文件，再以事务方式替换数据；恢复前建议先新建当前备份。
- CSV 用于通用查看和分析，不用于完整恢复。

## 隐私与安全

在“设置 → 隐私与安全”中可隐藏金额、启用系统生物识别应用锁以及选择深色、浅色或跟随系统主题。应用完全离线，但本地文件和导出的备份仍需由用户妥善保管。

## 升级与卸载

只有相同正式签名且更高 `versionCode` 的安装包才能直接升级。卸载应用会删除本地数据库；系统备份已禁用，因此卸载前必须手动导出 `.pbk`。
