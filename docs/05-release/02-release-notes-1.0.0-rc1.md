# PersonalBookkeeping 1.0.0-rc1 版本说明

这是首个本地发布候选版本，面向个人离线记账。

## 主要能力

- 支出、收入和转账记账，支持账户与分类管理。
- 流水查询、组合筛选、编辑、删除和撤销。
- 月度概览、分类排行、趋势、下钻和预算状态。
- 完整 `.pbk` 备份/恢复与 CSV 导出。
- 金额遮罩、系统生物识别应用锁和深色/浅色/跟随系统主题。
- 完全离线运行，不申请网络权限。

## 本候选版改进

- Release 启用 R8 与资源收缩，加入 Baseline Profile。
- 完成大字体、窄屏、可访问语义和设置页滚动硬化。
- 建立 API 28/36 回归、核心覆盖率和 10,000 条数据性能基准。

该候选产物尚未使用正式密钥签名，不应对外分发。
