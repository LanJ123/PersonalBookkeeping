# ADR-005：禁用系统自动备份与设备迁移

- 状态：已接受
- 日期：2026-07-21

## 背景

Android Auto Backup 默认可包含数据库和内部偏好并上传到云端，这与本项目“无静默上传、由用户主动选择备份位置”原则冲突。

## 决策

设置 `allowBackup=false`，并为 Android 11 及以下、Android 12 及以上分别配置全排除规则，包括 cloud backup 和 device transfer。迁移只使用用户主动创建的 `.pbk`。

## 后果

隐私语义清晰，但用户若未主动备份，卸载或丢机后无法恢复。应用在形成有效数据后提供克制的备份提醒，并在目标 ROM 上验证规则。
