# ADR-006：稳定 API 36 构建基线

- 状态：已接受
- 日期：2026-07-21

## 背景

Android 17 / API 37 已进入测试阶段，但官方 SDK 稳定平台发布记录当前仍以 Android 16 / API 36 为稳定项。应用不需要 API 37 专有能力。CR-002 已恢复原平台方案。

## 决策

MVP `compileSdk=36`、`targetSdk=36`、`minSdk=28`。API 37 模拟器只用于可选前向兼容检查，不作为环境、工程初始化或发布门槛；正式升级另做依赖、行为变化和设备验证。

## 后果

减少预览工具链和本机资源风险；不能立即使用 API 37 新能力，但本项目没有此需求。未来 target 升级需更新构建基线和强制兼容测试。
