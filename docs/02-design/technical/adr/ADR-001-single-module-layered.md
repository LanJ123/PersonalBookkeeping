# ADR-001：单应用模块与包分层

- 状态：已接受
- 日期：2026-07-21

## 背景

MVP 是单人开发、单平台、功能边界清晰的本地应用。按 feature 拆多个 Gradle 模块会增加构建脚本、导航契约和依赖管理成本。

## 决策

产品代码放在 `:app`，通过 ui/domain/data/database/backup/security 包和依赖方向保持边界。性能测试单独使用 `:benchmark`。

## 后果

初期构建与重构简单，但包边界依赖编译器不能完全强制。代码评审和架构测试需防止 UI 直接引用 DAO。只有出现真实构建时间、多人并行或复用需求时才拆模块。
