# 核心交互流程

## 1. 首次使用到第一笔支出

```mermaid
flowchart TD
    A["首次启动"] --> B["创建默认账本、现金账户和分类"]
    B --> C["空首页：记下第一笔"]
    C --> D["支出编辑器"]
    D --> E{"金额、分类、账户有效？"}
    E -- "否" --> F["字段就地提示并保留输入"]
    F --> D
    E -- "是" --> G["原子保存"]
    G --> H["首页刷新并显示可撤销反馈"]
```

## 2. 编辑交易的一致性流程

```mermaid
flowchart TD
    A["打开流水详情"] --> B["编辑"]
    B --> C["加载原交易快照"]
    C --> D["修改并校验"]
    D --> E["数据库事务：撤销旧影响并应用新影响"]
    E --> F{"提交成功？"}
    F -- "是" --> G["刷新详情、余额、统计和预算"]
    F -- "否" --> H["回滚事务，保留编辑输入"]
```

## 3. 统计分类下钻

`统计选择月份 → 点击分类排行 → 打开流水页 → 固定月份 + 支出类型 + 分类条件 → 查看/编辑某笔 → 返回仍保留筛选 → 返回统计仍保留月份`

## 4. 预算设置

`首页预算入口/设置 → 输入月总预算 → 可选设置分类预算 → 即时预览已有支出占用 → 保存 → 首页和统计刷新`

分类预算之和允许大于总预算，因为两者分别用于提示，不做强制资金分配；界面需说明该规则。

## 5. 完整恢复

```mermaid
flowchart TD
    A["选择备份文件"] --> B["只读读取 manifest 与校验"]
    B --> C{"格式、版本、完整性通过？"}
    C -- "否" --> D["拒绝恢复并说明原因；当前账本不变"]
    C -- "是" --> E["显示备份时间、版本和记录数"]
    E --> F{"用户确认全量替换？"}
    F -- "否" --> G["退出；当前账本不变"]
    F -- "是" --> H["创建本机回滚快照"]
    H --> I["事务性恢复"]
    I --> J{"一致性检查通过？"}
    J -- "是" --> K["提交并展示恢复结果"]
    J -- "否" --> L["回滚到原账本并展示失败原因"]
```

## 6. 应用锁

`冷启动或后台超过设定时长 → 内容先遮罩 → 调起系统认证 → 成功后展示原页面；失败/取消继续遮罩；系统不支持时不可开启并解释原因。`
