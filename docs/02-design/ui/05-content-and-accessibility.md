# 内容与无障碍规范

## 1. 文案原则

- 使用日常财务用语：写“流水”“转账”“月预算”，不向用户暴露数据库、借贷记账法等实现术语。
- 按结果命名操作：`保存`、`创建备份`、`导出 CSV`、`确认恢复`，避免含糊的“确定”。
- 错误说明“发生了什么 + 如何继续”，例如：`备份文件校验失败，当前账本没有变化。请重新选择完整的备份文件。`
- 成功反馈简短且可验证，例如：`已保存支出 ¥25.50`、`已导出 286 笔流水`。
- 不用羞辱或施压文案。超预算写事实，不写“乱花钱”“控制力差”。

## 2. 金额和日期

- 界面金额使用 `¥1,234.50`；列表收入带 `+`，支出带 `-`，转账标为 `转账 ¥1,234.50`。
- 输入允许用户省略小数，失焦后格式化；错误输入不自动猜测或静默截断。
- 当年日期可显示 `7月21日`，跨年显示 `2025年12月31日`；详情保留精确时间。
- 记账编辑器的日期和时间分别使用有标签的选择控件，初始值为当前本地日期时间；确认后立即在控件上回显，取消选择不改变原值。
- 周期文案写明完整边界：周统计示例 `2026年7月20日–26日`，月统计示例 `2026年7月`，年统计示例 `2026年`。
- 流水年月筛选使用完整标签 `2026年7月`；非法年份写 `请输入 1900 至 9999 年之间的有效年月`。
- 首页与流水页的日期组头统一使用 `7月26日 星期日`；小计固定按 `支 ¥25.50  收 ¥100.00` 顺序，转账不进入两项小计。
- 流水日期卡片内每笔次要信息统一写作 `12:30 · 微信零钱`；转账写作 `12:30 · 现金 → 银行卡`。
- 分类排行笔数统一写作 `12笔`，金额和占比分别写作 `¥1,280.00`、`39%`，不能只在图中标注。
- 统计类型筛选使用完整 `支出 / 收入` 文案；汇总随类型写作 `月支出、日均支出、比上月支出、收支结余` 或对应收入版本。
- 趋势纵轴和柱顶金额保留人民币符号；环形图引导标签采用 `分类名 百分比`，例如 `餐饮 39%`。
- 空值写清含义，例如备注为空时显示 `无备注`，而非 `--`。

## 3. 触控与键盘

- 交互目标至少 48dp；相邻危险和确认操作保持充分间距。
- 分段控件的选中项同时提供背景、字重和 `selected` 语义，不能仅用蓝色区分。
- 底部线性图标必须保留可读文字标签；居中新增按钮暴露“新增流水”操作名称。
- 浅色与深色模式均保持正文、次要文字、分割线和状态色的可辨识对比度。
- 输入框具备可见标签，不能只依赖 placeholder。
- 系统返回手势与页面返回按钮行为一致；恢复进行中拦截退出时需说明。
- 焦点顺序跟随视觉顺序；弹窗关闭后焦点回到触发控件。
- 日期与时间选择器的确认、取消目标至少 48dp；返回手势等同取消，不能静默提交半成品选择。
- 年月选择器中 12 个月均为独立可选控件；关闭后焦点回到当前年月按钮。

## 4. 屏幕阅读器

- 图标按钮需要可访问名称，例如 `隐藏金额`、`下一周`、`下一月`、`下一年`。
- 流水日期卡片先朗读日期与当日支出/收入小计；组内流水行整体可读为：`支出，餐饮，25元5角，微信零钱，今天12点30分`。
- 周/月/年和全局支出/收入切换控件需读出选中状态；统计焦点顺序保持“粒度→周期→收支类型→汇总→趋势→环形图→分类排行→对比”。
- 环形图语义逐项描述 `分类、笔数、金额、占比`，下方排行提供等价可操作文本；趋势图逐点描述标签和当前类型金额，周期对比图逐项描述周期标签、当前类型和金额；金额遮罩时语义中不包含真实金额。
- 预算进度读作：`月预算5000元，已用3280元50角，百分之65，剩余1719元50角`。

## 5. 颜色、缩放与隐私

- 收支、选中、错误和预算状态不能只由色相区分，必须配合文字、正负号、图标或图案。
- 环形图色块必须与带分类名、笔数、金额和占比的排行配对；单分类时仍显示完整环形和 `100%` 文本。
- 环形图直接百分比标签、趋势纵轴和柱顶金额在大字体时允许适度缩小图形区或换行，但不得与主数值重叠；排行仍是完整数据的可读兜底。
- 深色模式下图表、分割线、输入和错误文本需保持对比；不对系统强制颜色做假设。
- 字体放大至 1.3 倍时允许数值换行，不能重叠、截断主操作或产生水平滚动。
- 应用锁启用时，认证前以及最近任务缩略图中不渲染真实金额与备注。
