# UX 设计规格

> 版本：v1.3（CR-006 图表与分组调整）
> 更新日期：2026-07-27
> 输入基线：需求 v1.3
> 变更来源：用户补充的首页日分组、支出/收入月报总览、趋势、环图和柱图参考图

## 1. 设计目标

1. 首页到保存普通支出不超过一次页面切换；金额、分类、账户在首屏完成。
2. 首页先回答“今天花了多少、本月花了多少、本月收入多少”，再提供当前月全部流水；历史月份查询进入流水或统计页。
3. 所有统计都能回到组成它的流水，避免图表成为数据孤岛。
4. 数据恢复、删除等高风险操作强调对象、影响与可回滚性。
5. 极简不是隐藏关键状态：筛选、预算超支、停用账户和恢复结果必须清楚可见。

## 2. 导航模型

底部 4 个一级入口：`首页`、`流水`、`统计`、`设置`。居中的“记一笔”作为全局主操作，但不新增第五个信息层级。

- 首页：今日支出、本月支出、本月收入、按天聚合的当前月全部流水及每日收支小计；不提供周期切换。
- 流水：完整事实列表，负责年月筛选、搜索、组合筛选、详情、编辑和删除。
- 统计：周/月/年切换、对应周期导航、全局支出/收入筛选、2×2 汇总、单类型趋势、分类构成、周期对比和下钻。
- 设置：预算、账户、分类、备份恢复、CSV 导出、外观和应用锁。

返回规则：编辑器取消后返回发起页面；保存后返回发起页面并显示成功反馈。统计下钻进入带固定周期与分类筛选条件的流水页，返回时保留统计粒度和所选周期。

## 3. 记账编辑器

顶部使用 `支出 / 收入 / 转账` 分段选择，默认支出。字段顺序依据使用频率：

1. 金额：自动聚焦，人民币符号固定展示；不预填 0。
2. 分类：显示最近使用与全部分类；收入/支出切换时更换集合。
3. 账户：默认最近一次同类型交易使用的活动账户。
4. 日期、时间：直接展示两个可点击选择控件，默认当前日期时间；新建和编辑都允许修改。
5. 备注：可选多行输入。
6. 保存：始终有可见文字，不使用只有图标的确认按钮。

转账模式将“分类”替换为“转出账户 / 转入账户”，当两者相同时立即就地报错。键盘上的完成操作不等于保存，避免误提交。

保存按钮是编辑器内容的终点；下方不展示“最近流水”或历史交易列表，避免把查账任务混入记账流程，也不在后台为编辑器订阅最近流水。

## 4. 首页层级

- 第一层：今日支出，作为首页主数值。
- 第二层：本月支出、本月收入，作为并列辅助数值。
- 第三层：标题“本月流水（N笔）”及当前自然月全部流水。流水按保存的本地日期倒序分组；组头显示 `M月d日 星期X` 与 `支 ¥x.xx  收 ¥x.xx`，组内按发生时间倒序；点击一行进入详情。
- 首页不展示月份切换、结余、预算或历史月份；这些能力分别由流水、统计和预算页面承接。
- 空账本显示三项明确的 `¥0.00` 和“本月还没有流水”，全局“记一笔”仍是主操作。

## 5. 流水与筛选

- 默认按发生时间倒序、按天分组；组头显示日期与当日收支小计。
- 搜索框下提供年月快捷筛选。未选择时显示“按月筛选”；选择后显示“上一月 / YYYY年M月 / 下一月 / 清除”。
- 年月选择器包含四位年份输入和 12 个月份选项；合法范围为 1900～9999 年。查询区间为所选月月初至月末。
- 顶部搜索匹配备注；筛选按钮显示生效数量，例如“筛选 2”。
- 筛选面板包含自定义日期、类型、账户、分类；年月可与类型、账户、分类、备注组合。应用自定义日期后解除年月快捷选中状态。
- 详情页先显示交易事实，再放编辑和删除操作。删除位于低强调区域且二次确认。

## 6. 统计与预算

- 统计默认当前自然月，顶部提供 `周 / 月 / 年` 三段切换；自然周从周一开始，自然月从 1 日开始，自然年从 1 月 1 日开始。
- 每种粒度都可进入上一周期或下一周期，所选粒度与周期独立于首页和预算状态。
- 周期导航后提供全局 `支出 / 收入` 筛选；切换时汇总、趋势、分类构成、下钻类型和最近五周期对比同步更新，粒度与周期不重置。
- 首屏顺序：2×2 周期总览 → 所选类型趋势 → 所选类型分类构成 → 所选类型最近五周期对比。
- 总览固定为：`周期支出/收入`、`日均支出/收入`、`比上一周期支出/收入`、`收支结余`。
- 周、月趋势按日展示，年趋势按月聚合；一次只绘制所选类型，左侧显示人民币纵轴金额刻度，并提供屏幕阅读器等价描述。
- 分类构成主体使用环形图表达占比，中心显示对应类型总额；每个扇区通过引导线直接标注分类名与百分比。
- 环形图下方按金额降序提供等价排行，每行同时显示序号、色标、分类名、笔数、占比、金额和下钻箭头；环形颜色不是唯一信息。
- 点击分类排行整行下钻到完全相同的周/月/年日期范围、收支类型与分类流水。
- 最近五周期对比使用柱状图，每个柱顶部显示该周期所选类型的金额，柱下显示周期标签。
- 预算同时显示“已用 / 总额 / 剩余”，80% 使用“接近预算”文字，100% 使用“已超支”文字，不能只靠颜色。
- 预算仍按自然月管理，不随统计页的周/年粒度变化。

## 7. 视觉方向

采用克制、轻量、数据优先的视觉：单一高强调操作色；收支方向除颜色外始终带 `支出/收入/转账` 文本或正负号；卡片只用于真正的汇总或输入边界，不为每一行制造容器。

具体颜色、字体、间距 token 在视觉设计/技术设计交界阶段结合 Material 3 固化，本阶段不锁死品牌色。

## 8. 原型范围

交互原型覆盖首页按天聚合的当月流水、流水年月筛选、周/月/年统计、全局支出/收入联动、带金额轴的单线趋势、直接标百分比的环形构成、带柱顶金额的周期对比、设置、三类记账、日期时间和保存反馈。它是低保真行为样例，不代表最终字体、图标、颜色和精确尺寸。
