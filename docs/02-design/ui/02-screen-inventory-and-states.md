## 2. 必备状态

| 页面族 | 正常 | 空状态 | 校验/错误 | 长任务/特殊状态 |
|---|---|---|---|---|
| 首页 | 三项汇总 + 当前月流水日分组 + 每日收支小计 | 未记账：三项为 `¥0.00`，显示“本月还没有流水”，全局记账入口保持可见 | 汇总或月流水失败：说明失败，不展示错误数字 | 金额遮罩、应用锁、跨时区本地日期、当月大列表惰性渲染 |
| 记账 | 默认当前日期时间且可编辑；保存后结束，不显示最近流水 | 无活动分类/账户：引导创建 | 金额/账户/分类就地错误；无效日期时间不提交；保存失败保留输入 | 编辑已停用引用时仍展示原值；系统日期/时间选择器 |
| 流水 | 日期卡片分组、每日收支小计、可选年月条件 | 从未记账 | 年份非法：保持选择器并说明；筛选无结果：清除条件；查询失败：重试 | 日期卡片跨分页边界保持连续、大列表惰性加载、跨年上/下月 |
| 统计 | 周/月/年、全局类型筛选、2×2 汇总、单类型趋势、环形构成和周期对比 | 当前类型无数据：汇总为零，构成卡说明，可继续切另一类型 | 计算失败：重试 | 单分类、很多分类、零收入、全零纵轴、跨月自然周、闰年仍可读 |
| 预算 | 进度与分类列表 | 未设置：说明 + 设置入口 | 非法金额就地提示 | 接近、达到、超支三状态 |
| 账户/分类 | 活动与停用分区 | 不允许没有最低必需默认数据 | 重名、被引用不能删除 | 排序、停用确认 |
| 备份 | 历史操作摘要 | 从未备份 | 空间不足、写入失败、用户取消 | 生成中、成功、取消 |
| 恢复 | 文件摘要 | 未选文件 | 损坏、不兼容、校验失败 | 校验中、恢复中、回滚、成功 |
| 导出 | 日期范围与字段说明 | 范围内无流水 | 目标不可写、写入失败 | 导出中、成功、取消 |

## 3. 删除确认文案规则

- 普通流水：`删除这笔 ¥25.50 的餐饮支出？删除后账户余额和统计会同步更新。`
- 转账：`删除这笔 ¥1,000.00 的转账？两个账户余额都会同步恢复。`
- 账户/分类有历史引用时不提供“删除”，改为“停用”，并说明历史记录不受影响。

## 4. 状态保存

- 底部一级页面切换保留统计粒度/周期/全局收支类型，以及流水选中年月、搜索词和滚动位置，直到用户主动更改或应用进程被回收；首页始终回到真实今天和当前自然月。
- 记账表单被系统短暂打断后恢复金额、类型、分类、账户、日期、时间和备注；用户明确取消后清除。
- 恢复、备份不能因页面旋转或切到后台而重复启动。
