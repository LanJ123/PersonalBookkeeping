## 4. 统计

```text
┌──────────────────────────────┐
│  统计                        │
│  [ 周 ] [ 月 ] [ 年 ]         │
│  ‹      2026 年 7 月      ›  │
│        [ 支出 ] [ 收入 ]      │
│ ┌──────────────────────────┐ │
│ │月支出 ¥3,280.50  日均¥105│ │
│ │比上月支出 -¥720  结余¥4719│ │
│ └──────────────────────────┘ │
│                              │
│  月支出趋势                  │
│ ¥400 ───╭╮──────╭─╮         │
│ ¥200 ───╯╰──────╯ ╰──       │
│   ¥0 ─────────────────       │
│                              │
│  支出分类构成                │
│          ╭────────╮          │
│ 餐饮39%╱ ╭────╮   ╲ 交通16% │
│       │  │3280│    │         │
│        ╲  ╰────╯   ╱         │
│          ╰────────╯          │
│  1 餐饮 12笔 39%   -1,280.00 │
│  2 居住  3笔 30%   -1,000.00 │
│  3 交通  8笔 16%     -520.00 │
│                              │
│  月支出对比                  │
│  ¥800 ¥1900 ¥900 ¥1500 ¥3280│
│   ▂      ▆    ▃    ▅    █    │

│                              │
│ 首页    流水    统计    设置  │
└──────────────────────────────┘
```

周统计把趋势横轴固定为周一至周日；月统计按当月日期；年统计按 1～12 月聚合。切换粒度后所有模块使用同一日期范围；切换支出/收入会同步刷新 2×2 汇总、单条趋势线、环形构成/排行、下钻类型和柱状对比。
