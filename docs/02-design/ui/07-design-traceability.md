# 设计追踪矩阵

> 基于需求 v1.3 与 UX 设计 v1.4（CR-004～CR-007）。

| 需求 | UX 设计响应 | 页面/流程 |
|---|---|---|
| FR-001～003 | 默认配置、设置入口、认证前遮罩 | S-001、S-010、S-057 |
| FR-010～016 | 三模式编辑器、日期时间选择、字段校验、保存即结束（无最近流水）、保存/撤销、删除确认 | S-020～022、S-032 |
| FR-020～024 | 分类/账户管理、停用而非破坏历史 | S-052、S-053 |
| FR-030～033 | 连续日期卡片、每日收支小计、年月快捷筛选、前后月、搜索、组合筛选、空结果 | S-030～032 |
| FR-040～045 | 首页今日/本月摘要、当月流水日分组与每日小计；周/月/年统计、全局支出/收入、2×2 汇总、带金额纵轴的单线趋势、直接标百分比的环形构成、分类笔数/金额/占比、带柱顶金额的周期对比和同周期同类型下钻；月预算状态文本 | S-010、S-040、S-051 |
| FR-050～055 | 备份与 CSV 分离、恢复摘要和回滚状态 | S-054～056 |
| NFR-001～005 | 无在线入口、系统文件选择、系统认证、内容遮罩 | 设置与应用锁流程 |
| NFR-010～013 | 失败保留输入、原子编辑/转账、恢复回滚 | 编辑与恢复流程 |
| NFR-020～023 | 首屏层级克制、长任务进度和防重复 | 首页、流水、备份/恢复 |
| NFR-030～034 | 中文、深浅主题、大字体、非颜色单一表达 | 全局规范 |

当前所有 MVP FR/NFR 都有对应页面、流程或全局 UX 规则。CR-006 的首页日分组/小计由 S-010 承接，统计全局类型联动与图表数据标签由 S-040 承接；CR-007 由 S-030 承接，把流水结果区统一为连续日期卡片。历史月份明细仍由流水负责，汇总、图表、排行和下钻均来自同一事实流水范围。
