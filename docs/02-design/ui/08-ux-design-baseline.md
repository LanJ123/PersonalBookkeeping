## v1.1 变更基线（CR-004）

| 项目 | 内容 |
|---|---|
| 变更版本 | v1.1 |
| 提出日期 | 2026-07-26 |
| 提出方式 | 用户提供 4 张参考图并明确列出 3 项界面改动 |
| 影响页面 | 首页 S-010、记账编辑器 S-020、统计 S-040 |
| 不变范围 | 四主导航、流水、设置、月预算、数据格式、备份格式 |

v1.1 覆盖 v1.0 中受影响的冻结条目：

- 首页固定展示今日支出、本月支出、本月收入；月份查询、预算和最近流水不再占用首页。
- 统计独立支持自然周、自然月、自然年，并同步展示汇总、收支趋势、支出分类构成和最近五周期对比。
- 新建与编辑流水都直接展示日期、时间选择控件，默认当前本地日期时间；确认后的发生时间、时区和本地日期一并保存。
- 预算仍以自然月为周期；统计页切换周/年不会改变预算月份或首页当前月。

## v1.2 变更基线（CR-005）

| 项目 | 内容 |
|---|---|
| 变更版本 | v1.2 |
| 提出日期 | 2026-07-26 |
| 提出方式 | 用户连续补充 4 项界面要求并提供分类构成参考图 |
| 影响页面 | 首页 S-010、记账编辑器 S-020、流水 S-030/031、统计 S-040 |
| 不变范围 | 四主导航、设置、月预算、数据实体、数据库 schema、备份格式 |

v1.2 覆盖 v1.1 中受影响的冻结条目：

- ~~首页只展示三项汇总，不展示最近流水。~~ 首页在三项汇总下展示当前自然月全部流水；历史月份仍不在首页切换。
- 流水页增加年月选择、上一月、下一月和清除月份；可与其他条件组合，自定义日期范围会解除年月快捷选中。
- 记账编辑器以保存按钮结束，不展示“最近流水”，也不为该页面订阅最近流水数据。
- 分类构成采用环形图并支持支出/收入切换；排行逐类展示笔数、金额、占比，点击后按相同周期、类型、分类下钻。

## v1.3 变更基线（CR-006）

| 项目 | 内容 |
|---|---|
| 变更版本 | v1.3 |
| 提出日期 | 2026-07-27 |
| 提出方式 | 用户补充首页日分组、统计支出/收入总览及三类图表标注参考图 |
| 影响页面 | 首页 S-010、统计 S-040 |
| 不变范围 | 四主导航、记账编辑器、流水筛选、设置、月预算、数据库 schema、备份格式 |

v1.3 覆盖 v1.2 中受影响的冻结条目：

- 首页当前自然月流水按每笔保存的本地发生日期分组；组头固定显示日期、星期及当日支出/收入小计，组内按发生时间倒序。
- ~~分类构成卡内单独切换支出/收入。~~ 支出/收入切换提升到统计页全局状态，统一驱动汇总、趋势、分类构成、下钻和周期对比。
- 汇总固定使用 2×2 布局：周期总额、日均金额、比上一周期差额、收支结余；标签随周/月/年和支出/收入变化。
- 趋势只绘制当前类型并显示人民币纵轴；环形图直接标注分类百分比；最近五周期柱图逐柱显示金额。
- 分类排行仍逐类显示笔数、金额和占比，作为图表精确值与无障碍操作入口。

## v1.0 已冻结的设计决策

- 首页、流水、统计、设置构成四个一级入口，全局提供“记一笔”。
- ~~首页先展示自然月支出，再展示收入、结余、预算和最近流水。~~ 已由 CR-004 的精简首页取代。
- 记账编辑器默认支出，支持收入与转账；高频字段及日期时间选择位于首层。
- 流水按日分组，支持关键词与组合筛选；统计分类可下钻到流水。
- 统计以数值、趋势、环形构成、分类排行和周期对比共同表达，图形不依赖颜色作为唯一信息。
- 设置按财务、数据、偏好与隐私分组，备份恢复和 CSV 导出明确分离。
- 删除与恢复使用影响说明、确认和可回滚设计。

## 基线完整性检查

- 所有 MVP FR/NFR 均已映射到页面、流程或全局 UX 规则。
- 正常、空、筛选无结果、校验失败、长任务、锁定和恢复失败状态已定义。
- 内容、金额、日期、触控、屏幕阅读器、大字体与隐私遮罩规则已定义。
- 当前没有阻塞技术设计的产品或 UX 决策。

## 变更控制

基线后的导航、页面层级、关键字段顺序和主流程变化属于正式 UX 变更，应同步更新 UX 规格、评审记录、追踪矩阵和受影响的需求/技术/测试文档。CR-004～CR-006 已同步到 `docs/02-design/ui/01～08`；后续实现验证以本文件的 v1.3 变更基线为准。视觉 token、精确间距和组件实现方式只要不改变本基线行为，可作为细化项处理。
