# 设计阶段文档目录

设计阶段产物按关注点分开保存：

- [`ui/`](ui/)：产品交互、页面状态、流程、线框图、内容与无障碍、UX 评审及 UX 基线。
- [`technical/`](technical/)：技术栈、系统架构、数据库、备份、安全、测试、风险、追踪矩阵以及配套机器可读产物。

## 存放规则

- 用户可见行为、页面布局、交互与文案规范进入 `ui/`。
- 实现方式、平台约束、数据结构、安全和验证策略进入 `technical/`。
- ADR、SQL DDL 和 JSON Schema 跟随技术设计保存在 `technical/` 内。
- 跨 UI 与技术的追踪关系分别保存在各自目录，项目总入口统一由 [`docs/README.md`](../README.md) 提供。
