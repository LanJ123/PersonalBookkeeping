# 信息架构与核心流程

## 1. 一级导航

建议使用 4 个底部入口，并用全局主按钮发起记账：

| 一级页面 | 核心内容 |
|---|---|
| 首页 | 本周期收支/结余、预算进度、最近流水、快速记账 |
| 流水 | 日期分组列表、搜索、组合筛选、详情与编辑 |
| 统计 | 月份切换、分类排行/占比、每日趋势、分类下钻 |
| 设置 | 账户、分类、预算、备份恢复、CSV 导出、外观与应用锁 |

## 2. 页面清单

- 首次启动：轻量说明 → 可直接使用默认配置。
- 记账编辑器：支出 / 收入 / 转账三个模式。
- 流水详情：查看、编辑、删除。
- 搜索与筛选：关键词、日期、类型、分类、账户。
- 账户列表 / 账户编辑。
- 分类列表 / 分类编辑排序。
- 预算设置。
- 备份、恢复确认、导出范围选择。
- 应用锁认证页。

## 3. 核心流程

### 新增支出

`首页/任意主页面 → 点击记一笔 → 默认支出 → 输入金额 → 选分类 → 确认账户 → 保存 → 返回来源页并刷新`

设计要求：记住最近使用的支出账户；日期默认为现在；备注和修改日期收进“更多”区域；保存按钮在键盘出现时仍可触达。

### 编辑流水

`流水列表/统计下钻 → 流水详情 → 编辑 → 校验 → 原子保存 → 返回详情/列表`

### 恢复备份

`设置 → 备份与恢复 → 选择备份文件 → 只读校验 → 展示摘要/警告 → 用户确认 → 创建回滚快照 → 原子替换 → 一致性检查 → 成功`

任何校验或替换失败均不得留下“半恢复”状态。

## 4. 通用界面状态

所有数据页面必须设计：加载、正常、空数据、筛选无结果、校验错误和不可恢复错误状态。危险操作使用明确对象名称和结果说明；可撤销的操作优先提供撤销。

## 5. 无障碍与易用性

- 可点击目标建议至少 48dp；文字缩放后核心信息不可截断。
- 颜色不能成为预算超支或收支类型的唯一表达，需配合文字/图标。
- 金额输入使用数字键盘，但保留清晰的币种和小数规则。
- 图表同时提供文本数值/排行，避免仅靠图形读取。
