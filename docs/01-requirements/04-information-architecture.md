# 信息架构与核心流程

## 1. 一级导航

建议使用 4 个底部入口，并用全局主按钮发起记账：

| 一级页面 | 核心内容 |
|---|---|
| 首页 | 今日支出、本月支出、本月收入、按天聚合的当月全部流水、每日收支小计、快速记账 |
| 流水 | 日期分组列表、年月筛选、搜索、组合筛选、详情与编辑 |
| 统计 | 周/月/年切换、全局支出/收入筛选、2×2 周期汇总、单类型趋势与金额纵轴、环形构成百分比、分类笔数/金额/占比、带柱顶金额的周期对比、分类下钻 |
| 设置 | 账户、分类、预算、备份恢复、CSV 导出、外观与应用锁 |

## 2. 页面清单

- 首次启动：轻量说明 → 可直接使用默认配置。
- 记账编辑器：支出 / 收入 / 转账三个模式。
- 流水详情：查看、编辑、删除。
- 搜索与筛选：年月快捷筛选、关键词、自定义日期、类型、分类、账户。
- 账户列表 / 账户编辑。
- 分类列表 / 分类编辑排序。
- 预算设置。
- 备份、恢复确认、导出范围选择。
- 应用锁认证页。

## 3. 核心流程

### 新增支出

`首页/任意主页面 → 点击记一笔 → 默认支出 → 输入金额 → 选分类 → 确认账户 → 确认或修改日期时间 → 保存 → 返回来源页并刷新`

设计要求：记住最近使用的支出账户；日期时间默认为现在并直接可选；备注保持可选；保存按钮在键盘出现时仍可触达；编辑器不展示任何最近流水列表。

### 按月查询流水

`流水 → 按月筛选 → 输入年份并选择月份 → 查询 → 展示该自然月全部匹配流水 → 上一月/下一月连续浏览 → 清除月份`

年月条件可与类型、账户、分类和备注组合；如改用自定义日期范围，以自定义范围为准并解除年月快捷选中状态。

### 编辑流水

`流水列表/统计下钻 → 流水详情 → 编辑 → 校验 → 原子保存 → 返回详情/列表`

### 恢复备份

`设置 → 备份与恢复 → 选择备份文件 → 只读校验 → 展示摘要/警告 → 用户确认 → 创建回滚快照 → 原子替换 → 一致性检查 → 成功`

任何校验或替换失败均不得留下“半恢复”状态。

## 4. 通用界面状态

所有数据页面必须设计：加载、正常、空数据、筛选无结果、校验错误和不可恢复错误状态。危险操作使用明确对象名称和结果说明；可撤销的操作优先提供撤销。

## 5. 无障碍与易用性

- 可点击目标建议至少 48dp；文字缩放后核心信息不可截断。
- 颜色不能成为预算超支或收支类型的唯一表达，需配合文字/图标。
- 金额输入使用数字键盘，但保留清晰的币种和小数规则。
- 图表同时提供文本数值/排行，避免仅靠图形读取。
