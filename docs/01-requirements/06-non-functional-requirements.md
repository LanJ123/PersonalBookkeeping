# 非功能需求

## 1. 隐私与安全

- **NFR-001** MVP 默认不声明 `INTERNET` 权限，不集成广告、统计、崩溃上传或第三方用户画像 SDK。
- **NFR-002** 业务数据库位于应用私有目录；外部文件通过 Android Storage Access Framework 由用户显式选择。
- **NFR-003** 应用锁复用 Android 生物识别/设备凭据，不自行保存指纹、面容或系统解锁密码。
- **NFR-004** 最近任务预览在应用锁启用时不得暴露账本内容；日志不得输出金额、备注或完整备份路径等敏感信息。
- **NFR-005** 恢复文件视为不可信输入，需限制大小、校验结构并防止路径穿越/资源耗尽。

## 2. 可靠性与数据完整性

- **NFR-010** 交易写入、账户影响和关联更新必须原子提交。
- **NFR-011** 应用被系统杀死或写入失败后，不得出现半笔转账或部分恢复。
- **NFR-012** 完整备份恢复测试必须验证记录数、引用完整性、账户余额和周期汇总。
- **NFR-013** 数据库升级不得静默丢字段或清库；每次 schema 迁移均有自动化测试。

## 3. 性能（暂定验收设备为中端 Android 手机）

- **NFR-020** 冷启动至可交互首页 P95 ≤ 2 秒。
- **NFR-021** 1 万笔流水下，流水首屏和月份切换 P95 ≤ 1 秒。
- **NFR-022** 普通新增/编辑交易点击保存至反馈 P95 ≤ 500 毫秒。
- **NFR-023** 长任务（备份、恢复、大范围导出）显示进度且不阻塞 UI；可取消时应支持取消。

指标需在选定目标设备和 Release 构建上测量；若设备未确认，报告中必须标注测试环境。

## 4. 兼容性与可用性

- **NFR-030** 支持 Android 9（API 28）及以上，手机竖屏优先；平板可用但 MVP 不专项适配。
- **NFR-031** 简体中文为 MVP 唯一界面语言；货币为人民币。
- **NFR-032** 支持浅色/深色/跟随系统；系统字体放大至 1.3 倍时核心流程仍可完成。
- **NFR-033** 关键控件提供可访问名称；预算状态和收支方向不只依赖颜色。
- **NFR-034** 飞行模式下记账、查询、统计、预算以及设备本地文件的备份恢复均可用。

## 5. 可维护性与质量

- **NFR-040** 业务规则与 Android UI 分离，金额、周期、余额和备份校验可做 JVM 单元测试。
- **NFR-041** 核心计算逻辑行/分支覆盖率目标 ≥ 80%；不以单一总覆盖率替代关键场景测试。
- **NFR-042** 构建可复现，依赖版本锁定；Release 禁用调试日志并启用基础代码收缩检查。
- **NFR-043** 所有用户可见文案集中管理，不在业务代码中散落硬编码。
