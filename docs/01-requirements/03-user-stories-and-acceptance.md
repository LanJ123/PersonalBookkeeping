# 用户故事与验收标准

## US-001 快速记录支出

作为用户，我希望快速记录一笔支出，以便流水和本月统计立即准确更新。

- Given 已存在可用账户和支出分类，When 输入 25.50 元并保存，Then 新流水出现且对应账户减少 25.50 元。
- When 金额为空、为 0、负数、超过两位小数或超出上限，Then 不可提交并在金额处说明原因。
- When 保存成功，Then 本月支出、分类统计和预算占用同步增加 25.50 元。

## US-002 记录收入

作为用户，我希望记录收入，以便账户余额和月度结余准确。

- 保存收入后，对应账户余额和本月收入等额增加。
- 收入不占用支出预算。

## US-003 账户转账

作为用户，我希望记录账户间转账，而不把资金移动误算为收支。

- 转出与转入账户必须不同且均可用。
- 保存后转出账户减少、转入账户增加相同金额，总资产不因同币种转账改变。
- 转账不进入收入、支出和预算统计；编辑或删除时两端同时成功或同时失败。

## US-004 查找与修改流水

作为用户，我希望按条件找到并修改错误流水。

- 关键词匹配备注；类型、日期、分类、账户筛选可组合使用。
- 编辑金额、类型、账户或分类后，旧影响完全撤销，新影响只应用一次。
- 无结果时可一键清除筛选返回完整列表。

## US-005 管理账户和分类

作为用户，我希望按自己的习惯维护账户和分类。

- 名称去除首尾空格后不能为空；同类型下分类名称不可重复，活动账户名不可重复。
- 已有历史流水的账户/分类停用后，历史显示不丢失且新增表单不再默认提供。
- 停用当前默认项时，系统要求选择新的默认项或自动选择首个可用项并提示。

## US-006 查看月度概览与统计

作为用户，我希望了解当月收支结构和趋势。

- 月份切换后，收入、支出、结余、分类和趋势使用同一统计周期。
- 分类统计总和与同周期计入统计的支出流水总和一致。
- 点击分类后，流水筛选条件与图表所用周期、分类一致。

## US-007 设置预算

作为用户，我希望设置月总预算和分类预算，以便了解剩余额度。

- 预算为正数，修改后即时按当前周期已有支出重算。
- 达到 80% 显示预警状态，达到/超过 100% 显示超支状态，但不阻止继续记账。
- 被标记为不计预算的交易（后续能力）以及收入、转账不占预算。

## US-008 完整备份与恢复

作为用户，我希望数据可由自己保管，并能在重装或换机时恢复。

- 备份完成后显示文件名、时间、大小和成功状态；取消选择文件不产生错误备份。
- 损坏、未知格式或不兼容版本在修改当前数据前被拒绝，并说明原因。
- 恢复确认页显示备份时间和记录数量；恢复成功后实体数量与关键汇总一致。
- 恢复任一步失败时，原账本保持可用；全量替换前存在自动回滚快照。

## US-009 导出 CSV

作为用户，我希望导出通用格式，用于个人归档和表格分析。

- 导出文件为 UTF-8，中文、逗号、引号和换行备注被正确转义。
- 金额以十进制文本输出两位小数，不输出内部“分”整数。
- 导出范围、行数和应用内同条件流水一致。

## US-010 隐私保护

作为用户，我希望本地财务数据不被应用静默上传。

- 未启用任何外部文件操作时，核心流程无需网络。
- Release 包不包含网络权限、广告 SDK 或分析 SDK。
- 启用应用锁后，从后台超时返回时需完成系统认证；认证失败不展示账本内容。
