# 竞品与市场调研

## 1. 调研目标与边界

目标不是复制完整商业产品，而是识别个人离线记账中已经被验证的核心模式。调研时间为 2026-07-21，以产品官网/官方指南为主。

## 2. 产品观察

| 产品 | 观察到的能力 | 对本项目的启示 |
|---|---|---|
| 钱迹 | 收支/转账、预算、账户资产、多账本、统计、日历、搜索、导入导出和丰富自定义 | 快速流水、账户、统计、数据可携带是成熟主干；高级债务/报销等应延后 |
| 鲨鱼记账 | 极简操作、统计、月度/分类预算、Excel 导出、周期账单、日历、提醒、搜索、密码 | 首版应保证低步骤记账；预算、导出、搜索的实用性高 |
| Money Manager | 引导、备份恢复、导入导出、预算、账户资产、提醒与可配置首页 | 首次使用需默认数据和轻量引导；恢复能力不能作为事后补丁 |
| Cashew | 分类、日历、周期交易、净资产、多账户、日期筛选，强调避免财务术语堆砌 | 用普通语言和清晰概览，减少专业会计概念暴露 |

## 3. 共同模式

1. **录入效率决定留存**：金额、分类、账户和时间是最常用字段，备注等应为可选。
2. **流水是事实源**：列表、搜索、筛选和编辑是纠错基础，统计不能替代流水管理。
3. **账户与转账需一致**：只有收入/支出不足以解释不同钱包间的资金移动。
4. **预算与统计形成反馈**：月度汇总、分类占比、趋势和预算进度足以覆盖个人复盘。
5. **本地产品必须重视可恢复性**：完整备份用于灾难恢复，CSV 用于通用分析，两者目的不同。
6. **高级自动化代价高**：自动记账依赖 Android 无障碍、通知、悬浮窗和后台存活，并会随支付 App 页面变化而持续适配，不适合作为首版依赖。

## 4. MVP 取舍

### 纳入

- 手工录入收入、支出和账户转账。
- 自定义账户和收支分类。
- 流水查看、编辑、删除、搜索和筛选。
- 月度概览、分类统计、收支趋势。
- 月总预算与分类预算。
- 完整本地备份/恢复、CSV 导出。
- 可选应用锁与系统级生物识别。

### 延后

- 周期账单、记账提醒、桌面小组件、多账本、收据图片。
- CSV 导入、债务/报销/退款专用流程、多币种。
- 无障碍自动记账、OCR、云同步、多人共享、投资理财。
