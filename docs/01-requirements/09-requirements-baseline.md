## 已冻结的 MVP 边界

- 单用户、单账本、简体中文、人民币、自然月。
- Android 9（API 28）及以上，实际主力机型号在首次真机测试前补录；此项由 CR-002 恢复。
- 手工收入、支出、转账；账户、分类、流水搜索筛选。
- 首页概览、月度分类/趋势统计、总预算与分类预算。
- 完整本地备份恢复、CSV 导出、可选系统应用锁。
- 默认无网络权限，无账号、广告、分析、云同步或自动记账。
- 周期账单、提醒、导入和图片属于 P1，不进入 MVP。

## 基线完整性检查

- PRD 中的 MVP 功能已映射到用户故事与计划验证方式。
- 数据与非功能要求覆盖金额精度、事务、恢复、隐私、性能和兼容性。
- 风险与延期范围已显式记录。
- 需求阶段不存在阻塞 UX 设计的开放产品决策。

## 变更控制

基线后的需求变化不能直接修改实现范围。应先在决策日志新增记录，并同步更新 PRD、用户故事、追踪矩阵和受影响的设计/测试文档。主力机型号登记和文案微调可作为澄清项处理；改变平台下限、币种、账本数量或 P1/MVP 边界属于正式范围变更。
