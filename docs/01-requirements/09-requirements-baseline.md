## 已冻结的 MVP 边界

- 单用户、单账本、简体中文、人民币、自然月。
- Android 9（API 28）及以上，实际主力机型号在首次真机测试前补录；此项由 CR-002 恢复。
- 手工收入、支出、转账；账户、分类、流水搜索筛选。
- 首页今日/本月概览和按天聚合的当月全部流水；流水年月筛选；周/月/年全局支出/收入筛选、汇总、分类构成、趋势与周期对比；总预算与分类预算。
- 完整本地备份恢复、CSV 导出、可选系统应用锁。
- 默认无网络权限，无账号、广告、分析、云同步或自动记账。
- 周期账单、提醒、导入和图片属于 P1，不进入 MVP。

## 基线完整性检查

- PRD 中的 MVP 功能已映射到用户故事与计划验证方式。
- 数据与非功能要求覆盖金额精度、事务、恢复、隐私、性能和兼容性。
- 风险与延期范围已显式记录。
- 需求阶段不存在阻塞 UX 设计的开放产品决策。

## 变更控制

基线后的需求变化不能直接修改实现范围。应先在决策日志新增记录，并同步更新 PRD、用户故事、追踪矩阵和受影响的设计/测试文档。主力机型号登记和文案微调可作为澄清项处理；改变平台下限、币种、账本数量或 P1/MVP 边界属于正式范围变更。

## 基线后变更

- CR-001（2026-07-21）：最低支持版本由 API 28 调整为 API 26，并删除 API 37 前向兼容测试项；不改变 MVP 功能范围。
- CR-002（2026-07-21）：撤销 CR-001，恢复最低 API 28，并恢复 API 37 前向兼容模拟器测试；当前以 CR-002 为准。
- CR-003（2026-07-22）：API 37 本机前向兼容验证因资源限制改为可选，不改变发布平台要求。
- CR-004（2026-07-26）：首页汇总精简、统计支持周/月/年、记账可选择日期时间。
- CR-005（2026-07-26）：首页增加当前月全部流水，流水增加年月筛选，记账移除最近流水，统计增加支出/收入环形构成及分类笔数/金额。
- CR-006（2026-07-27）：首页流水按本地日期分组并显示每日收支小计；统计增加全局支出/收入联动、2×2 汇总及图表金额/百分比标签。
