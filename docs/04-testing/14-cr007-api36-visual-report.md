# CR-007 API 36 视觉验证报告

> 版本：v1.0  
> 执行日期：2026-07-29  
> 被测版本：`1.0.0-rc1` benchmark  
> 设备：PBK_API_36 模拟器，Android 16 / API 36

## 1. 结论

流水页日期卡片已在 API 36 模拟器完成实际页面核对：

- 同一天的组头和多笔流水位于一个连续圆角卡片内；
- 组头显示日期、星期、当日支出和收入小计；
- 组内显示分类、发生时间、账户或转账流向、备注和金额；
- 同日流水使用分割线，不再每笔单独成卡；
- 相邻日期之间保留卡片间距；
- 年月、类型和更多筛选入口保持可用。

## 2. 环境与数据

最新 benchmark APK 通过 `:app:assembleBenchmark` 构建并成功安装。benchmark Provider 成功生成 10,000 笔可复现流水：

```text
Result: Bundle[{count=10000, elapsed_ms=1510}]
```

首日样例为转账，因此组头显示 `支 ¥0.00  收 ¥0.00`；下一日样例为支出，组头显示 `支 ¥1,225.25  收 ¥0.00`，用于同时验证零小计和非零小计。
