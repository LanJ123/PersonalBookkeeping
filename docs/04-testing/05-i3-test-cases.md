# I3 测试用例

> 版本：v1.0
> 执行日期：2026-07-22～2026-07-23
> 范围：US-006、US-007，FR-040～045，以及 I1/I2 回归门禁

| ID | 场景 | 层级 | 预期 | 结果 |
|---|---|---|---|---|
| TC-I3-001 | 自然月闰年、月末与跨年边界 | JVM | `periodKey`、起止 epoch day 正确且终点为下月首日 | 通过 |
| TC-I3-002 | 预算 79.99%、80%、99.99%、100% 与超额 | JVM | 80% 起“接近预算”，100% 起“已超支”，无浮点边界误判 | 通过 |
| TC-I3-003 | 月汇总排除转账 | Room | 收入仅含 INCOME、支出仅含 EXPENSE，结余为收入减支出 | 通过 |
| TC-I3-004 | 分类排行与月支出对账 | Room | 分类金额合计等于月支出，金额降序且历史分类可见 | 通过 |
| TC-I3-005 | 日趋势与月汇总对账 | Room | 各日收入/支出合计分别等于月汇总 | 通过 |
| TC-I3-006 | 最近五笔限定当前月 | Room | 只取当前月，排序稳定，最多五笔 | 通过 |
| TC-I3-007 | 总预算新增、编辑与清除 | Room/Repository | 同作用域保持唯一；编辑即时重算；清除后无告警 | 通过 |
| TC-I3-008 | 分类预算独立计算 | Room/Repository | 只统计对应分类支出；收入、转账及其他分类不计入 | 通过 |
| TC-I3-009 | 首页空状态与预算状态文案 | Compose | 无流水显示“记下第一笔”；80%/100% 有明确非颜色文案 | 通过 |
| TC-I3-010 | 统计排行、趋势与下钻 | Compose/ViewModel | 金额和占比可读；点击分类产生同月+支出+分类筛选 | 通过 |
| TC-I3-011 | 跨一级入口保留所选月份 | ViewModel/Compose | 首页、统计、预算共享月份，返回统计不重置 | 通过（API 36 冒烟） |
| TC-I3-012 | 预算输入校验 | JVM/Compose | 空、零、负数、超上限拒绝；合法正数可保存 | 通过 |
| TC-I3-013 | I1/I2 自动化回归 | JVM/Instrumented | 金额、记账、管理、分页、编辑删除撤销全部通过 | 通过 |
| TC-I3-014 | API 28 最低版本矩阵 | Instrumented | 数据库和 Compose 用例全部通过 | 11/11 通过 |
| TC-I3-015 | API 36 目标版本矩阵 | Instrumented/冒烟 | 用例通过，安装启动无崩溃，I3 界面可操作 | 11/11 通过 |
| TC-I3-016 | Debug/Release、Lint 与依赖验证 | 构建 | 两种 APK 构建成功，Lint 0 error，依赖摘要有效 | 通过 |
| TC-I3-017 | Manifest、备份与 schema 审计 | 静态/构建 | 无 INTERNET；`allowBackup=false`；schema v1 identity hash 不变 | 通过 |
