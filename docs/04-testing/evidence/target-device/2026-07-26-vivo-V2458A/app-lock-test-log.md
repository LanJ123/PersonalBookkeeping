# 应用锁与系统认证真机人工测试记录

> 日期：2026-07-26
> 设备：vivo V2458A，Android 16 / API 36
> 被测版本：`1.0.0-rc1` Debug
> 结论：通过

## 执行结果

| 场景 | 预期与结果 |
|---|---|
| 启用应用锁 | 调起 Android 系统认证；认证成功后开关生效 |
| 后台超时 | 离开应用超过固定 30 秒后返回，显示应用锁定页，真实财务内容不先显示 |
| 取消认证 | 保持锁定，不能进入账本内容 |
| 成功认证 | 使用系统生物识别或设备凭据后恢复应用内容 |
| 熄屏重入 | 熄屏超过 30 秒并重新进入应用后再次要求解锁 |
| 最近任务预览 | 应用锁开启时不暴露真实金额与备注 |

设备持有人按真机矩阵完成操作并明确确认“功能没问题”。应用不接触或保存 PIN、密码、指纹及认证结果；认证全部由 Android 系统界面完成。
