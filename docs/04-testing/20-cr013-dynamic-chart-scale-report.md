# CR-013 动态统计图验证报告

> 日期：2026-07-30  
> 设备：API 36 模拟器 `PBK_API_36`、vivo V2458A（Android 16，无线 ADB）  
> 范围：趋势图动态纵轴、支出/收入独立缩放、选中金额气泡、分类构成、周期柱状图

## 1. 实现核对

- 动态刻度由当前可见数据峰值计算，不再使用固定 ¥100 或跨筛选上限。
- 优先生成六档人民币刻度，步长从适合手机阅读的序列中向上选择；全零数据使用紧凑回退范围。
- 趋势图包含竖向网格、渐变面积、可点击选中点、虚线和金额气泡。
- 柱状图复用动态上限，使最高柱不占满绘图区，为柱顶金额保留空间。

## 2. 自动化结果

| 检查 | 结果 |
|---|---|
| `testDebugUnitTest assembleDebug` | 通过 |
| `ChartScaleTest`：小额、百元、全零、峰值包含 | 4/4 通过 |
| API 36 `InsightsScreensTest` | 3/3 通过 |
| 支出/收入筛选后的统计标题、汇总、分类与对比图 | 通过 |

补充说明：为给空模拟器生成测试流水而单独运行
`PhysicalDeviceComposeUiTest#transactionEditorSavesAndReturnsToEveryRootSource`
时，API 36 模拟器未在限定滚动次数内找到 `transaction-save`，该辅助造数用例失败且未作为本次图表通过依据。随后使用统计页专用 Compose 测试和已有真实数据的 vivo 真机完成验证。

## 3. 真机结果

| 场景 | 实际结果 |
|---|---|
| 月支出 ¥734.30 | 纵轴自动为 ¥150～¥900 六档 |
| 点击 30 日峰值 | 气泡显示“30日支出 ¥734.30”，未越过卡片右边界 |
| 最后一个零值日 | 点位贴合基线，气泡显示 ¥0.00 |
| 月收入 ¥2,500.00 | 切换收入后纵轴独立重算为 ¥500～¥3,000 六档 |
| 月横轴 | 显示 1/5/9/13/17/21/25/29 日，网格对齐 |
| 支出分类构成 | 环图显示 93%/7%，排行显示 8笔/1笔及对应金额 |
| 最近五周期柱图 | 五个柱顶金额均显示，最高柱保留顶部标签空间 |
