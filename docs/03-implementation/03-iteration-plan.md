# 第 4 阶段迭代实现计划

> 版本：v1.4
> 生效日期：2026-07-22  
> 当前状态：I0～I5 本地工程工作完成；正式签名与目标真机门禁待外部条件

## 1. 实现方式

采用小步垂直切片。每个切片同时完成领域规则、数据层、UI、自动化测试、人工验收和文档更新；不先堆积全部页面再补数据正确性。

每次迭代的退出条件遵循项目完成定义：验收标准通过，异常和边界已覆盖，核心逻辑有测试，Debug/Release 可构建，文档和追踪已同步。

## 3. I0/I1 任务分解

1. 固定版本目录与 Gradle Wrapper，创建 `:app` 单模块。
2. 设置 `minSdk=28`、`compileSdk=36`、`targetSdk=36`、Java/Kotlin 17。
3. 配置无网络权限 Manifest、禁用系统备份、中文资源和 Compose 主题。
4. 实现 `Money` 金额解析/格式化及边界测试。
5. 实现 Room schema v1、触发器、余额视图、初始化种子和导出 schema。
6. 实现创建交易用例与最小“记一笔”界面，并对收支/转账形状做双层校验。
7. 执行单测、构建、Lint；在 API 28/36 上做安装启动与最小流程验证。

## 4. I5 前暂不做

- `:benchmark` 模块；在 I5 性能迭代创建。
- API 37 启动测试；本机内存条件改善后再补。
- 正式发布签名、发布候选配置与最终用户手册；开发期 Release APK 仍未签名。

## 5. 追踪与记录

- 每次实现结果追加到 `06-implementation-log.md`。
- 测试用例与报告进入 `docs/04-testing/`。
